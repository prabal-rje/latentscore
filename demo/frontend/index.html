SIGGRAPH Talks '26 · NIME '26 · Open Source

Turn vibes into ambient sound.

LatentScore is an open-source procedural ambient music synthesizer and browser studio for Python, TypeScript/JavaScript, and Rust. Describe a mood in plain words and generate reactive ambient soundscapes locally with no GPU required.

Open Live Browser Studio

Text to Procedural Ambient Music

Describe any scene such as "quiet morning desk" or "rainy midnight coffee shop" and synthesize seamless ambient audio locally on CPU.

Python, JavaScript/TypeScript, and Rust SDKs

Install via pip, npm (zero runtime dependencies), or Cargo (optional lock-free cpal playback) to add reactive local music to editors, games, focus timers, and web apps.

Browser Studio with 14,035 Moods and Auto Drift

Run quantized embedding retrieval, live 18-parameter tuning, and endless similarity-gradient Auto Drift directly in your browser with zero server calls.
